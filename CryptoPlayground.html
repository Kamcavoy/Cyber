📖 Algorithm Explanation

Caesar Cipher – shifts each letter by a fixed number.

Example: ABC (+3) → DEF

⚠️ Very weak – easily broken by brute force.

AES (Advanced Encryption Standard) – symmetric block cipher.

Key sizes: 128 / 192 / 256 bits

🔒 Strong – used by governments and militaries.

📜 Caesar Cipher

Encrypt: E(x) = (x + shift) mod 26
        Decrypt: D(x) = (x - shift) mod 26

🔐 AES Parameters

Mode: CBC
        Padding: PKCS7
        IV: Random (auto-generated)
